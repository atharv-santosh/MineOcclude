This immutable package transfers literal `person-c-layout-config-v0.4` geometry and hash-bound runtime authorities. Person C has not fit or altered Person E matrices. Person E must create the exact outputs named in `expected_person_e_output_schema.json`.

The old E correspondence and Phase 3 homography-authority files remain frozen historical evidence. They are out of domain for v0.4 because every layout's literal marker coordinates changed. No offset, `+0.5` correction, layout-ID shift, coordinate renumbering, role adapter, or compatibility transform is permitted.

The E validation gate remains median wall-parallel absolute error `<= 0.2` blocks and p95 `< 0.5` blocks on independent v0.4-bound points. Until all six layouts pass and the E-owned validation receipt exists, C6A is not authorized. No runtime binaries, screenshots, personal credentials, or world data are copied here; external evidence is referenced by path, size, and SHA-256.
